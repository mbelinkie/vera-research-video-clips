## Local completion record

- **Implemented:** server-only Cognito authorization-code + S256 PKCE/nonce flow, exact configured HTTPS callback and logout, one-time state and browser binding, JWT validation with `aws-jwt-verify`, bounded in-memory opaque sessions, refresh/revocation, host-only Secure HttpOnly SameSite=Lax cookies, strict origin/Host/CSRF checks, server-verified subject-to-stable-catalog identity registration, and per-request membership checks. Browser BFF does not expose worker or local-agent routes.
- **Files:** `apps/cloud-api/src/browser-auth/*`, cloud API composition and routes, `packages/config`, `packages/catalog`, browser session UI and API wrapper, `.env.example`, `README.md`, package dependencies, and focused/integration/browser fixtures.
