## Approved workflow and downstream scope

- **Sources and Library** are the two top-level tabs. A source opens its capture view inside Sources. The whole row opens the source with a pointer, while its title is the keyboard target and row actions stay independent. Keep the shared text-size control, stable excerpt-first rows, wide docked Library detail, compact full-width detail, and focus restoration. Update the three-tab language in the #81 implementation brief when refining that issue. Carry Sources and Library Topic filters into #81. [Research UI #81](https://github.com/mbelinkie/vera-research-video-clips/issues/81)
- **Manual quotes** bind to the existing article when extraction fails. Show saved excerpts on the source and focus the newest quote after Save. Save and add another focuses an empty quote field with the same source. Typed Add supports Article and Book with a first quote, incomplete citations, and optional person and role separate from the byline. Attribution can be added after logging. Carry citation editing and the broader existing/offline-source cases through #80 and #81. [Typed quotes #80](https://github.com/mbelinkie/vera-research-video-clips/issues/80)
- **Video and extension intake** keep one optional editable Why added note and separate timestamped Moments. Logged clips sit above Moments. A moment seeks and pauses, Start clip here sets In, and a logged clip plays its range. The earlier extension-comment fixtures and the simulated pop-up were removed. Extension implementation evidence is tracked independently. [Research #101](https://github.com/mbelinkie/vera-research-video-clips/issues/101) · [Merged extension PR #103](https://github.com/mbelinkie/vera-research-video-clips/pull/103)
- **Library playback and export** show an image in still detail with hover and keyboard preview. Clips play their saved ranges in detail and use a frame from that range when available. Sources use the video poster. Keep the unavailable state and saved citation. Desktop Export starts collapsed and opens destination and preset controls with an explicit Start export. Limited Web offers Open in Desktop for the selected item. Carry real playback, media availability, frame extraction, export, handoff, and accessibility verification through #15 and the relevant media implementation issues. [Research #15](https://github.com/mbelinkie/vera-research-video-clips/issues/15) · [Local media #84](https://github.com/mbelinkie/vera-research-video-clips/issues/84)
- **Hiding and comments** preserve the r14 defaults. Hide Source keeps the source’s Library items. Library Hide is project-wide, reversible, and prevents new Authoring uses while preserving existing placements. Show hidden can restore items. All returns to the default view. Delete requires confirmation and offers Hide if the item is in a script. Hidden entries stay visible on their source. Carry a visible Hidden label there as an implementation follow-up. Unread comments have a gold indicator and text, and the mock marks them read when leaving detail. Keep both the Authoring picker rule and the existing-placement rule in the cross-product implementation handoff.
